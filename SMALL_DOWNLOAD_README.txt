This is the same updated LeNota project with /ask and Ask Selection natural-language image generation, but without node_modules (reinstallable JS dependencies).

On the first build, from LeNota-mobile/apps/desktop run: npm ci
Then build/run the project using the included scripts (e.g., bash RUN_SMOOTH_APP.sh from project root).
Note that building may require Rust/Tauri prerequisites. See IMAGE_GENERATION.md for capability limits.
