# AI Context & Request Preview (LeNota 0.33.3)

The app no longer uploads all note containers on the current page by default when you run `/ask` or Ask Selection.

## Quick use

1. Write `/ask your question` in a note and press Enter. The request review opens before contacting the AI. The `/ask` command stays in the note until the response succeeds.
2. The default **Only note containing /ask** excludes text, tables, LaTeX, and AI answers in other containers. Earlier conversation history is disabled by default.
3. Pick a different context scope if needed:
   - **Only note containing /ask** (default for text questions)
   - **Choose note containers** (select any combination in a checklist; canvas selections are pre-checked)
   - **Entire page** (explicitly send all note text)
   - **No page context** (only the question)
4. Edit the outgoing question and **Outgoing page context** text directly before **Send to AI**. The character/token estimate is approximate. If you select a different scope, the editable preview is regenerated from that scope.
5. **Ask Selection** captures the selected image locally and shows the captured PNG before you confirm. The default for this action is the **selected image only** (no unrelated page text). You may add specific notes or the whole page if needed.
6. The small slider icon beside AI providers opens the default settings. On narrow mobile screens, open **AI providers → AI context · developer options**. Disabling **Review each request before sending** removes the extra step, while keeping the saved scope.

## What is sent

The provider receives the question, exactly the edited page-context string, and the selected screenshot PNG when applicable. The native AI worker adds fixed instructions for response structure (JSON, tables, math, etc.). Those fixed instructions and saved provider credentials are not editable through this dialog. The note labels/coordinate headings in the context textarea are part of the actual transmitted text.

No page or other container is read by the context builder unless it is included by the chosen scope. The "Include earlier AI exchanges" toggle is off by default and is restricted to the included notes when enabled. The app still validates up to 20 KB for questions, and 120,000 characters (within 160 KB UTF-8) of context; longer autogenerated previews are truncated with a warning. Screenshots are sent separately when using Ask Selection.

All AI settings are stored locally as `lenota:ai-context-options:v1`; no document format or native worker change was necessary. Existing ChatGPT → Gemini → OpenRouter provider fallback remains unchanged.
